# Environment provenance

Zero purchase / no paid generation. Curated locally from `/home/helper/venture-valley/assets/runtime`.

- **Quaternius Medieval Village MegaKit, Standard FREE** — https://quaternius.com/packs/medievalvillagemegakit.html ; CC0 1.0, archive license copied alongside. Eight modular glTF models: plaster straight/window/door wall, round door, brick roof front, tiled 8x8 roof, chimney, wooden fence. Associated buffers and referenced textures included. Texture maps resized to a maximum 512px for the mobile prototype. Models recombined into two cottages.
- **Kenney Nature Kit** — https://kenney.nl/assets/nature-kit ; CC0, archive license copied alongside. Curated plant_bushDetailed and flower_yellowC. Tree candidates were rejected during visual QA because their angular crowns did not fit; original rounded multicluster canopies are used instead.
- `cobble.png` — original deterministic illustrated cobblestone tile authored for this project using Pillow. No downloaded texture.
- `village_finish.gd` — original environment assembly; noise grass and rounded scenic hills authored in-engine.

Tier: free modular textured architecture + low-poly flat-color nature kit + authored connective materials. Not bespoke production art and not the same leaf-detail tier as the user's reference. Scenic hills are non-walkable framing; original ground, river, bridge, terrace and camp collider contracts remain authoritative. Cottage interiors are not gameplay spaces. Existing character files untouched.
