# Faith Over Giants expedition artwork

Original code-authored 2D SVG illustrations for this route: `expedition-landscape.svg`, `expedition-camp.svg`, and `fear-cloud.svg`. No external reference art, paid generation, or third-party graphics were used for these illustrations. They depict an illustrative learning expedition, not a historically reconstructed biblical location.

Michael is reused without recoloring or duplication from the project's existing owned `public/images/jr/games/shepherd-light-adventure/michael-trail-sprite.webp`. That atlas has nine columns and four directional rows. This route uses the first idle frame (background position 0% 0%, size 900% 400%). Michael is explicitly labeled Michael / Майкл; he is not labeled Joshua or Caleb. Helper strength is shown as a count, not invented canonical character duplicates. Existing guide dialogue remains separate; former CSS face avatars are replaced by decorative symbols.

The path highlight and Michael's position derive directly from existing `courseProgress`; clouds shrink and become more transparent with the active obstacle's real HP. The input target retains a stable size as cloud art diminishes. No timer, new economy, or gameplay rule is introduced.

Quality tier: original lightweight vector scenery plus an existing rendered character sprite, not premium real-time 3D. Browser/layout/build acceptance belongs to the director; this code-only worker did not run those processes.
